مراجعة الحدود ونصف قطر الزوايا (Borders & Radius)

معاينة بصرية منعزلة للمرجعية الهندسية والدلالية للحدود وأنصاف أقطار الزوايا. تتحقق هذه الصفحة من الفصل الصارم بين عقد لون الحدود وعقد هندستها، ومن دقة مقاييس نصف القطر المضبوط، دون استخدام أي ظلال أو أنماط مرتجلة.

سماكات الحدود المرجعية

Reference Border Width Scale (Physical Pixels)

تُعرف سماكات الحدود بوحدات البكسل الفيزيائي (px) حصراً، وتُستمد هذه العينات مباشرة من متغيرات Sass المرجعية دون مضاعفات بصرية.

بدون حدود (None)
$honesty-ref-border-width-0 0
سماكة افتراضية (1px)
$honesty-ref-border-width-1 1px
سماكة تأكيد (2px)
$honesty-ref-border-width-2 2px

أنماط الحدود المرجعية

Reference Border Stroke Styles

مقارنة نمط الخط الفيزيائي لسماكة 1px مع إثبات الدور الدلالي لنمط الخط المتقطع (dashed).

خط مصمت (Solid Stroke)
$honesty-ref-border-style-solid solid
خط متقطع (Dashed Stroke)
$honesty-ref-border-style-dashed dashed
دور دلالي متقطع (Semantic Dashed)
--honesty-border-style-dashed dashed

عقد لون الحدود مقابل عقد هندسة الحدود

Border Color Hierarchy vs Geometry Separation (Subtle / Default / Strong)

التسلسل البصري للحدود في Honesty ERP يتحقق بتغيير قوة لون الحد وليس زيادة سماكته. كافة العينات الثلاث أدناه تستخدم سماكة 1px تماماً عبر --honesty-border-width-default ونمط --honesty-border-style-default. لا يُستخدم 2px للحدود البارزة (Strong).

السمة الفاتحة (Light Theme) data-theme="light"
حد خفيف (Subtle Border) var(--honesty-border-subtle) 1px • solid
حد افتراضي (Default Border) var(--honesty-border-default) 1px • solid
حد بارز (Strong Border) var(--honesty-border-strong) 1px (ثابت) • solid
السمة الداكنة (Dark Theme) data-theme="dark"
حد خفيف (Subtle Border) var(--honesty-border-subtle) 1px • solid
حد افتراضي (Default Border) var(--honesty-border-default) 1px • solid
حد بارز (Strong Border) var(--honesty-border-strong) 1px (ثابت) • solid

سماكة التأكيد مقابل السماكة الافتراضية

Default Width (1px) vs Emphasis Width (2px)
قاعدة تصميم حاسمة سماكة التأكيد (2px emphasis) ليست معادلاً لمتغير --honesty-border-strong. الحدود البارزة (Strong) تمثل تدرجاً لونياً دلالياً في حين أن التأكيد (Emphasis) يمثل سماكة هندسية مخصصة لحالات استثنائية.
السماكة الافتراضية (1px)
--honesty-border-width-default 1px
سماكة التأكيد (2px)
--honesty-border-width-emphasis 2px

السلم المرجعي لنصف قطر الزوايا

Reference Corner Radius Scale

سلم هندسي مضبوط يعتمد على وحدة rem بالنسبة للجذر 16px، مع قدرة full بقيمة 9999px دون جعلها الجمالية الافتراضية.

0
$honesty-ref-radius-0 0
2
$honesty-ref-radius-2 0.125rem (2px)
4
$honesty-ref-radius-4 0.25rem (4px)
6
$honesty-ref-radius-6 0.375rem (6px)
8
$honesty-ref-radius-8 0.5rem (8px)
12
$honesty-ref-radius-12 0.75rem (12px)
full
$honesty-ref-radius-full 9999px
توثيق الحصر قيمتا 2px ($honesty-ref-radius-2) و 12px ($honesty-ref-radius-12) متاحتان في السلم المرجعي فقط ولا تمتلكان أي دور دلالي (Semantic Alias) في Candidate V1.

الأدوار الدلالية للزوايا

Semantic Radius Roles (Runtime CSS Variables)

أدوار دلالية تعبر عن الاستخدام الوظيفي. هذه العينات مستطيلات هندسية محايدة لمراجعة الشكل حصراً وليست مكونات فعلية كالأزرار أو البطاقات.

مربع تماماً (None)
--honesty-radius-none 0
أداة تحكم (Control)
--honesty-radius-control 0.25rem (4px)
سطح حاوي (Surface)
--honesty-radius-surface 0.375rem (6px)
طبقة طافية (Overlay)
--honesty-radius-overlay 0.5rem (8px)
قدرة كاملة (Full)
--honesty-radius-full 9999px

تركيب أ (A) سماكة افتراضية + لون افتراضي + زاوية سطح
