عائلة إدخال النصوص V1 دليل مراجعة حقول الإدخال القياسية والزجاجية في السمة العامة النشطة. عائلة عناصر الإدخال الأنماط والمظهر @for (variant of variants; track variant) { } الأحجام السبعة @for (size of sizes; track size) { } مصفوفة الحقول السلوك والاتجاه انقر أي مساحة غير مخصصة لإجراء داخل سطح الحقل لمراجعة التركيز والتفعيل الكاملين. CheckBox — المرجع المعتمد تنفيذ مباشر لهندسة وحالات وحركة erp-checkbox-3، مع استبدال Palette القالب بألوان النظام فقط. Standalone checkbox Control فقط بدون نص مرئي، مع نفس check-stroke وbox-pop والحالات المعطلة. Checkbox with title & sub-title المؤشر مضبوط بصريًا على السطر الأول للعنوان، والوصف له مقياسه الخاص. Switch mode نفس المكوّن والـmarkup؛ track وthumb فقط يغيران العرض، والحركة تنعكس منطقيًا مع RTL. Tile mode — multi-select الـindicator في الحافة المنطقية والبلاطة نفسها تحمل hover وfocus وselected surface. Variants Outline وFilled وSoft بنفس الـmarkup تمامًا؛ الاختلاف Token swap فقط وينطبق أيضًا على Switch. Outline — الافتراضي Filled Soft Indeterminate Select-all حقيقي؛ الأب يعكس الأبناء والشرطة تُرسم بنفس لغة حركة علامة الصح. Size scale نفس نسب القالب: SM 18px، MD 22px، LG 28px، XL 36px. State matrix Default وChecked وIndeterminate وDisabled وRead-only وInvalid عبر Checkbox وSwitch. Checkbox Switch Tile mode — single select هذا الجزء في القالب يستخدم native radio، لذلك يظل تابعًا لموجة RadioBox التالية ولا يتم تزويره داخل CheckBox. العائلة الرقمية اختيار الملفات والصور منتقيات التاريخ والوقت منتقيات الاختيار
