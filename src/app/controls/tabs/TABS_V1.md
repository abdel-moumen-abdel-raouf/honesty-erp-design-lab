# ErpTabs V1

`ErpTabs` owns one controlled active tab, disabled-tab exclusion, automatic
orientation-aware keyboard activation, RTL logical horizontal navigation,
collision-free tablist/tab/tabpanel semantics, focus visibility, active
indicator geometry, and reference-defined narrow behavior.

An item may provide convenience string `content`. Rich content uses a keyed
`ng-template erpTabPanel="tabId"` and may contain tables, forms, surfaces, or
custom controls. Header anatomy supports text, semantic icons, exact-reference
image presentation through `ErpAvatar`, and optional counts. Tabs does not own
application routing; a page may coordinate routing externally.

Current exact authority is `ERP-TABS.html`, SHA-256
`CFBFA876AC6521ED4A6BDBEB7AAF07D01B62F8808B65F5C749E0B06F44D8C9B9`.
It supersedes the former Nexlink reference and accelerated-wave waiver. Exact
variants are `underline | pill | solid | ghost`; `pills`, legacy directional
fades, header shapes, `count`, and `renderPanels=false` remain bounded opt-in
compatibility for existing consumers. Technical green does not equal Product
Owner visual acceptance.
