# ErpTabs V1

`ErpTabs` owns one active tab, disabled-tab exclusion, keyboard navigation, RTL logical navigation, tablist/tab/tabpanel semantics, focus visibility, and narrow-width overflow.

An item may provide convenience string `content`. Rich content uses a keyed `ng-template erpTabPanel="tabId"` and may contain tables, forms, surfaces, or custom controls. Tabs does not own application routing; a page may coordinate routing externally.
