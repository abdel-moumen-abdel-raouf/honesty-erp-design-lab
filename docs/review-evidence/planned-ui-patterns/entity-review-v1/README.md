# ErpEntityReview V1 evidence

`ErpEntityReview` is an original Honesty ERP presentation candidate. No
binding external visual reference was found or claimed. Its source authority is
the immutable `ErpEntityReviewContext` already published by the Entity Form
engine and the Product Owner's 2026-10-11 presentation-only authorization.

Run from a live Design Lab server:

```powershell
$env:HONESTY_REVIEW_URL='http://127.0.0.1:4999'
node tools/review/capture-planned-ui-evidence.mjs
```

The evidence covers desktop Light/RTL and 390 px Dark/LTR, one primary live
target, immutable field presentation, container response, clipping, overflow,
and browser diagnostics. Technical/internal evidence does not establish Product
Owner visual acceptance.
